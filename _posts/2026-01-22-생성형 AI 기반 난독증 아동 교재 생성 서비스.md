## 🤔 **문제 정의**

1. **PDF 원본 문서를 학습 서비스에서 활용 가능한 교재 데이터로 변환할 수 있을까?**
   - PDF 파일은 원본 문서 단위로 관리되기 때문에 학생의 학습 진행률이나 페이지별 학습 데이터를 직접 관리하기 어려움
   - 원본 파일과 학습 콘텐츠를 분리하여 관리할 수 있는 데이터 구조가 필요함

2. **원본 내용을 헤치지 않으면서 학습용으로 처리할 수 있을까?**
   - 학습 서비스에서는 전체 문서의 내용보다 페이지 단위의 콘텐츠 제공과 진행 상태 관리가 중요함
   - PDFBox를 활용하여 PDF 문서를 페이지 단위 텍스트로 추출하는 파싱 흐름이 필요함

3. **문서 업로드 이후 교재 생성 과정을 하나의 백엔드 흐름으로 구성할 수 있을까?**
   - 사용자 입장에서 PDF 업로드 만으로 하나의 교재가 생성되도록 해야 함
   - 문서 업로드, 파일 저장, 텍스트 추출, 교재 생성, 페이지 저장 과정이 순차적으로 연결되어야 함

4. **영어 원문을 생성형 AI를 통해 고퀄리티의 번역 결과를 얻을 수 있을까?**
   - 영어 원문을 한국어 학습 콘텐츠로 제공하기 위해 번역 품질과 출력 형식을 제어할 필요가 있음
   - 생성형 AI가 일관된 번역 결과를 반환하도록 프롬프트 구조를 설계할 필요가 있음

## 🥸 **설계 선택**

1. **PDF 원본 문서를 학습 서비스에서 활용 가능한 교재 데이터로 변환할 수 있을까?**
   - Document → Textbook → Page 구조로 교재 생성 데이터를 분리함
     - `Document`: 업로드된 원본 파일과 파일 메타데이터 담당
     - `Textbook`: 학습 교재 단위의 정보와 변환 상태 담당
     - `Page`: 페이지 번호, 원문 텍스트, 처리 콘텐츠, 읽기 수준, 단어 수 등 페이지 단위 학습 데이터 담당

1. **원본 내용을 헤치지 않으면서 학습용으로 처리할 수 있을까?**
   - PDF 전체를 하나의 텍스트로 처리하지 않고, 페이지 번호를 기준으로 텍스트를 분리하여 추출함
   - 추출된 페이지 텍스트를 `Page` 엔티티 생성 흐름과 연결하여 페이지 단위 학습 콘텐츠로 저장할 수 있도록 구성함

1. **문서 업로드 이후 교재 생성 과정을 하나의 백엔드 흐름으로 구성할 수 있을까?**
   - 문서 업로드 요청 시 `Document`를 먼저 생성하고, 파일 저장 이후 `Textbook`을 생성하도록 구성함
   - PDF 파싱 결과를 기반으로 페이지 수를 계산하고, 이후 각 페이지 데이터를 저장할 수 있는 구조로 연결함
   - 생성된 교재와 페이지 데이터를 보호자 또는 학생 관점에서 조회할 수 있도록 서비스 계층을 분리함

1. **영어 원문을 생성형 AI를 통해 고퀄리티의 번역 결과를 얻을 수 있을까?**
   - 영어 원문을 한국어 학습 콘텐츠로 변환하기 위해 번역 프롬프트를 구성함
   - 번역 결과가 학습 콘텐츠로 사용될 수 있도록 문장 의미와 난이도를 고려한 출력 형식을 설계함

	- PDF 파일 자체는 `Document`에서 관리하고, 실제 학습 교재 정보는 `Textbook`에서 관리하도록 분리함
	- 이를 통해 파일 메타데이터와 학습 진행 정보를 독립적으로 관리할 수 있었음

	- `Page` 엔티티를 분리함으로써 페이지별 원문, 처리 결과, 단어 수, 읽기 수준을 저장할 수 있었음

3. **문서 변환 작업은 업로드 요청과 분리하는 구조가 필요함을 확인함**
	- PDF 파싱과 페이지 데이터 생성은 파일 크기와 페이지 수에 따라 처리 시간이 달라질 수 있음
	- 업로드 요청과 변환 흐름을 분리함으로써 장시간 요청 대기를 줄일 수 있었음

4. **AI 기반 번역은 프롬프트 설계에 따라 학습 콘텐츠 품질이 달라짐을 확인함**
	- 단순 번역 결과보다 난독증 아동의 읽기 부담을 고려한 문장 구조와 표현 난이도 조절이 중요함
	- 학습 콘텐츠로 활용 가능한 결과를 얻기 위해 입력 조건과 출력 형식을 명확히 제한할 필요가 있었음

## 🛠️ 핵심 시스템 {#impl}

### 1. Document → Textbook → Page 데이터 모델 설계

PDF 원본 파일과 학습 교재 데이터를 분리하기 위해 `Document` → `Textbook` → `Page` 구조를 설계함

```
Document
 └─ Textbook
     └─ Page
```

- `Document`는 업로드된 원본 파일의 제목, 원본 파일명, 파일 경로, 파일 크기, MIME 타입을 관리함
- `Textbook`은 교재 제목, 페이지 수, 학습률, 변환 상태를 관리함
- `Page`는 페이지 번호, 원문 텍스트, 처리된 콘텐츠, 읽기 수준, 단어 수, 복잡도, 페이지 처리 상태를 관리함

### 2. PDFBox 기반 페이지 단위 텍스트 파싱

```java
PDFTextStripper stripper = new PDFTextStripper();

for (int i = 1; i <= pageCount; i++) {
    stripper.setStartPage(i);
    stripper.setEndPage(i);

    String pageText = stripper.getText(document);
    pages.add(pageText);
}
```

- 업로드 요청 시 먼저 `Document`를 저장하여 문서 식별자를 확보함
- 파일 저장 이후 실제 파일 경로를 `Document`에 반영함
- PDF 파싱 결과를 기반으로 페이지 수를 계산하고 `Textbook`을 생성함
- 이후 페이지 변환 처리를 비동기 흐름으로 연결하여 업로드와 변환 책임을 분리함

Document document = documentRepository.save(document);

String filePath = storageService.store(

### 4. Spring Boot 기반 교재 생성 REST API

```java
@PostMapping(
    value = "/documents/upload",
    consumes = MediaType.MULTIPART_FORM_DATA_VALUE
)
public ResponseEntity<CommonResponse<DocumentDto>> uploadDocument(
    @RequestParam("guardianId") Long guardianId,
    @RequestParam("file") MultipartFile file,
    @RequestParam("title") String title
) throws IOException {
    DocumentDto dto =
        convertProcessService.uploadDocument(
            guardianId,
            file,
            title
        );

    return ResponseEntity.ok(
        new CommonResponse<>("PDF 업로드 완료", dto)
    );
}
```

- `MultipartFile` 기반 PDF 업로드 API를 구현함
- 보호자 ID, 파일, 제목을 입력받아 문서 업로드와 교재 생성 흐름으로 연결함
- 응답은 공통 응답 객체로 감싸 클라이언트가 일관된 형태로 결과를 처리할 수 있도록 구성함

### 5. 생성형 AI 기반 영어 → 한국어 번역 프롬프트 설계

난독증 아동 대상 학습 콘텐츠는 일반 번역 결과를 그대로 사용할 경우 문장 길이가 길어지고 추상적 표현이 포함되어 학습 난이도가 높아지는 문제가 있었음
따라서 단순 번역이 아니라 학습 목적에 맞는 콘텐츠 생성이 가능하도록 논문을 바탕으로 생성형 AI 번역 프롬프트를 설계함

프롬프트 설계 시 다음 기준을 적용함

```
1. 문장의 의미는 유지
2. 문장 구조는 최대한 단순화
3. 어려운 어휘는 쉬운 표현으로 변환
4. 한 문장에는 하나의 의미만 포함하도록 구성
5. 페이지 단위 학습 콘텐츠로 저장 가능한 출력 구조 유지
```

이를 위해 System Prompt와 User Prompt를 분리하여 번역 모델의 역할과 출력 기준을 명확하게 정의함

예시:

```
System Prompt

당신은 9–13세 난독증이 있는 초등학생을 위한 학습 콘텐츠 번역 전문가입니다.
다음 영어 문장을 한국어로 번역하되 다음 기준을 반드시 따르세요.

1. 문장의 의미는 유지할 것
2. 문장 구조는 최대한 단순하게 유지할 것
3. 어려운 어휘는 쉬운 표현으로 변경할 것
4. 한 문장은 가능한 한 한 개의 의미만 포함하도록 작성할 것
5. 학습 콘텐츠로 사용할 수 있도록 자연스럽고 명확한 문장으로 작성할 것
```

User Prompt 예시:

```
다음 문장을 난독증 아동이 이해하기 쉬운 한국어 문장으로 번역하세요.

Sentence:
The ecosystem consists of many different organisms that interact with each other.
```

출력 예시:

```
생태계는 여러 생물이 함께 살아가는 환경입니다.
생물들은 서로 영향을 주고받습니다.
```

이와 같은 구조를 통해 긴 문장을 학습 목적에 맞는 짧은 문장 단위로 분리할 수 있도록 구성함

또한 번역 결과의 일관성과 안정성을 확보하기 위해 temperature 값을 낮게 설정하여 출력 변동성을 최소화함

```
requestBody.put("temperature", 0.3);
```
