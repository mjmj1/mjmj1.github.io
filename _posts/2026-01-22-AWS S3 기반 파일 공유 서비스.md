## 구현 상세 및 핵심 로직
### 0. 전체 처리 흐름
```
파일 업로드 요청
→ Box 생성
→ 비밀번호 존재 시 암호화
→ 파일별 S3 Object Key 생성
→ S3 업로드
→ Item 생성 및 Box 연결
→ Box ID 반환

다운로드 요청
→ Box ID 조회
→ 비밀번호 검증
→ S3 Object Key 목록 조회
→ 단일 파일이면 byte[] 다운로드
→ 다중 파일이면 ZIP 생성
→ 다운로드 응답 헤더 구성
→ 파일 응답 반환
```
### 1. Box-Item 기반 파일 공유 데이터 구조 설계
하나의 공유 단위인 Box에 여러 개의 파일 Item을 연결하는 구조로 설계
```  java
@Entity
@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
public class Box {
 
    @Id
    @GeneratedValue
    @Column(name = "box_id")
    private Long id;
 
    private String uploader;
    private String title;
    private String password;
    private Long fileSize;
    private LocalDateTime dateUploaded;
    private boolean crypted;
 
    @OneToMany(mappedBy = "box", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<Item> items = new ArrayList<>();
}
```

``` java
@Entity
@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
@Table(name = "item")
public class Item {
 
    @Id
    @GeneratedValue
    @Column(name = "item_id")
    private Long id;
 
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "box_id")
    private Box box;
 
    private String objectKey;
}
```
#### 코드 설명
- 하나의 공유 링크에서 여러 파일을 관리할 수 있도록 `Box`와 `Item`을 1:N 관계로 분리
- 실제 파일은 S3에 저장하고, DB에는 S3 접근 키인 `objectKey`만 저장
- 공유 단위의 제목, 업로더, 암호화 여부, 전체 파일 크기를 `Box`에서 관리

### 2. S3 Object Key 생성 및 업로드 요청 구조 구현
파일 업로드 시 원본 파일명을 그대로 사용하지 않고 시간 기반 prefix와 제목을 조합하여 S3 Object Key를 생성

``` java
private String createObjectKey(String title, String originFileName) {
 
    if (originFileName == null || !originFileName.contains(".")) {
        throw new IllegalArgumentException("올바른 파일을 추가해 주세요.");
    }
 
    String extension =
        originFileName.substring(originFileName.lastIndexOf('.') + 1);
 
    return "%d-%s.%s".formatted(
        System.currentTimeMillis(),
        title,
        extension
    );
}
```

- S3 업로드 요청은 파일 크기와 Content-Type을 포함해 생성

``` java
private PutObjectRequest buildPutObjectRequest(
        String objectKey,
        MultipartFile file
) {
    return PutObjectRequest.builder()
        .bucket(bucketName)
        .key(objectKey)
        .contentLength(file.getSize())
        .contentType(file.getContentType())
        .build();
}
```
#### 코드 설명
- S3 객체 식별을 위한 고유 Object Key 생성
- 파일 확장자 유효성 검증
- S3 저장 시 파일 크기와 MIME Type을 함께 전달하여 파일 메타데이터 유지

### 3. AWS S3 TransferManager 기반 파일 업로드 구현
AWS SDK의 S3TransferManager를 사용하여 서버에서 S3로 파일을 업로드하는 통신 모듈을 구현

``` java
public String uploadFileAndGetObjectKey(
        String title,
        MultipartFile file
) throws IOException {
 
    String objectKey =
        createObjectKey(
            title,
            Objects.requireNonNull(file.getOriginalFilename())
        );
 
    BlockingInputStreamAsyncRequestBody body =
        AsyncRequestBody.forBlockingInputStream(file.getSize());
 
    transferManager.upload(
        buildUploadRequest(objectKey, file, body)
    );
 
    body.writeInputStream(
        new ByteArrayInputStream(file.getBytes())
    );
 
    return objectKey;
}
```
#### 코드 설명
- 서버 애플리케이션과 S3 사이의 파일 업로드 흐름을 서비스 계층으로 분리
- 업로드 후 DB에는 실제 파일이 아닌 `objectKey`만 저장하여 파일 저장소와 비즈니스 데이터를 분리
- 업로드 성공 시 이후 다운로드에 사용할 S3 Object Key 반환

### 4. 파일 업로드와 Box-Item 저장 흐름 구현
Box 생성 시 비밀번호를 암호화하고, 여러 파일을 각각 S3에 업로드한 뒤 Item으로 연결

``` java
public Long saveBoxWithItems(
        BoxSaveDto boxDto,
        List<MultipartFile> files
) {
    String encodedPassword = null;
    boolean isCrypted = false;
 
    if (boxDto.getPassword() != null && !boxDto.getPassword().isEmpty()) {
        encodedPassword = passwordEncoder.encode(boxDto.getPassword());
        isCrypted = true;
    }
 
    Box box = Box.createBox(
        boxDto.getUploader(),
        boxDto.getTitle(),
        encodedPassword,
        isCrypted
    );
```

``` java
files.forEach(file -> {
 
    String objectKey;
 
    try {
        objectKey = s3Service.uploadFileAndGetObjectKey(
            boxDto.getTitle(),
            file
        );
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
 
    Item item = Item.createItem(objectKey);
 
    box.addItem(item, file.getSize());
});
 
boxRepository.save(box);
```

#### 코드 설명
- 공유 단위 생성과 파일 업로드 흐름을 하나의 서비스 로직으로 연결
- 비밀번호가 있는 경우만 암호화 처리하여 공개/비공개 공유를 모두 지원
- 여러 파일 업로드 시 `Box` 하나에 여러 `Item`을 연결하여 다운로드 시 단일 공유 단위로 처리

### 5. 비밀번호 기반 파일 접근 제어 구현
파일 다운로드 또는 삭제 요청 시 비밀번호가 설정된 Box인지 확인하고, 암호화된 비밀번호와 입력값을 비교

``` java
public boolean validatePassword(Long id, String inputPassword) {
    Box box = boxRepository.findById(id)
        .orElseThrow(() ->
            new ResponseStatusException(
                HttpStatus.NOT_FOUND,
                "Box not found"
            )
        );
 
    if (box.isCrypted()) {
        return passwordEncoder.matches(
            inputPassword,
            box.getPassword()
        );
    }
 
    return true;
}
```

- 다운로드 요청에서는 검증 실패 시 즉시 예외를 발생

``` java
public S3FileDetails downloadFile(Long id, String password) {
    if (!validatePassword(id, password)) {
        throw new ResponseStatusException(
            HttpStatus.UNAUTHORIZED,
            "Invalid password"
        );
    }
 
    Box box = boxRepository.findById(id)
        .orElseThrow(() ->
            new ResponseStatusException(
                HttpStatus.NOT_FOUND,
                "Box not found"
            )
        );
```

#### 코드 설명
- 공유 파일에 선택적 비밀번호 보호 기능 제공
- DB에는 평문 비밀번호가 아닌 인코딩된 값 저장
- 다운로드와 삭제 요청 모두 동일한 검증 로직 재사용

### 6. 단일 파일 다운로드와 다중 파일 ZIP 다운로드 분기 처리
Box에 포함된 파일 개수에 따라 단일 파일 다운로드와 ZIP 다운로드를 분기

``` java
public S3FileDetails downloadFile(Long id, String password) {
    if (!validatePassword(id, password)) {
        throw new ResponseStatusException(
            HttpStatus.UNAUTHORIZED,
            "Invalid password"
        );
    }
 
    Box box = boxRepository.findById(id)
        .orElseThrow(() ->
            new ResponseStatusException(
                HttpStatus.NOT_FOUND,
                "Box not found"
            )
        );
 
    String[] objectKeys = getObjectKeysByBoxId(id);
 
    if (isSingleFile(objectKeys)) {
        return downloadSingleFile(
            objectKeys[0],
            objectKeys[0],
            box.getFileSize()
        );
    }
 
    String title = getBoxTitleById(id) + ".zip";
 
    return downloadMultipleFiles(title, objectKeys);
}
```

``` java
private boolean isSingleFile(String[] keys) {
    return keys.length == 1;
}
```
#### 코드 설명
- 단일 파일은 원본 파일 형태로 바로 다운로드
- 여러 파일은 하나의 ZIP 파일로 묶어 공유 사용성을 개선
- 클라이언트는 동일한 다운로드 API를 사용하고, 서버가 내부적으로 파일 개수에 따라 응답 형태 결정

### 7. S3 파일 다운로드 및 byte[] 응답 구성
S3 Object Key를 기반으로 파일을 다운로드하고, 응답에 사용할 파일명·크기·내용을 `DTO`로 구성

``` java
private DownloadRequest<ResponseBytes<GetObjectResponse>>
buildDownloadRequest(String objectKey) {
 
    return DownloadRequest.builder()
        .getObjectRequest(buildGetObjectRequest(objectKey))
        .responseTransformer(AsyncResponseTransformer.toBytes())
        .build();
}
```

``` java
public byte[] downloads(String objectKey) {
    return transferManager
        .download(buildDownloadRequest(objectKey))
        .completionFuture()
        .orTimeout(3, TimeUnit.MINUTES)
        .join()
        .result()
        .asByteArray();
}
```

``` java
private S3FileDetails downloadSingleFile(
        String title,
        String objectKey,
        Long fileSize
) {
    byte[] bytes = downloads(objectKey);
 
    return new S3FileDetails(
        title,
        fileSize,
        bytes
    );
}
```

#### 코드 설명
- S3 다운로드 요청 생성 로직을 별도 메서드로 분리
- 다운로드 제한 시간을 설정하여 장시간 대기 방지
- 파일명, 파일 크기, 파일 내용을 하나의 응답 `DTO`로 묶어 `Controller`에서 응답 생성에 활용

### 8. 다중 파일 ZIP 압축 다운로드 구현
여러 개의 S3 파일을 다운로드한 뒤 서버에서 ZIP 파일로 묶어 반환

``` java
private S3FileDetails downloadMultipleFiles(
        String title,
        String[] objectKeys
) {
    try (
        ByteArrayOutputStream byteOutput =
            new ByteArrayOutputStream();
 
        ZipArchiveOutputStream zipOut =
            new ZipArchiveOutputStream(byteOutput)
    ) {
 
        for (String objectKey : objectKeys) {
 
            byte[] bytes = downloads(objectKey);
 
            ZipArchiveEntry zipEntry =
                new ZipArchiveEntry(objectKey);
 
            zipOut.putArchiveEntry(zipEntry);
 
            zipOut.write(bytes);
 
            zipOut.closeArchiveEntry();
        }
 
        zipOut.finish();
 
        return new S3FileDetails(
            title,
            byteOutput.size(),
            byteOutput.toByteArray()
        );
```

#### 코드 설명
- 여러 파일을 각각 다운로드하지 않고 하나의 ZIP 파일로 제공
- `Box` 제목을 ZIP 파일명으로 사용하여 공유 단위의 의미 유지
- ZIP 생성 실패 시 서버 오류로 처리하여 다운로드 실패를 명확히 전달

### 9. 다운로드 응답 헤더 구성
다운로드 응답 시 브라우저가 파일로 인식할 수 있도록 `Content-Disposition`, `Content-Length`, `Content-Type` 헤더를 구성

``` java
public static HttpHeaders getResponseHeader(
        String title,
        long size
) {
    HttpHeaders headers = new HttpHeaders();

    String encodedTitle =
        URLEncoder.encode(title, StandardCharsets.UTF_8);

    headers.setContentType(
        MediaType.APPLICATION_OCTET_STREAM
    );

    headers.setContentLength(size);

    headers.add(
        HttpHeaders.CONTENT_DISPOSITION,
        "attachment; filename=" + encodedTitle
    );

    headers.add(
        "Content-Transfer-Encoding",
        "binary"
    );

    return headers;
}
```

``` java
@PostMapping("/downloads/{id}")
public ResponseEntity<?> downloads(
        @PathVariable("id") Long id,
        @RequestBody Password body
) {
    S3FileDetails fileDetails =
        s3Service.downloadFile(
            id,
            body.password()
        );

    HttpHeaders responseHeader =
        DownloadResponseBuilder.getResponseHeader(
            fileDetails.fileName(),
            fileDetails.size()
        );

    return new ResponseEntity<>(
        fileDetails.content(),
        responseHeader,
        HttpStatus.OK
    );
}
```

#### 코드 설명
- 다운로드 시 파일명이 깨지지 않도록 UTF-8 인코딩 처리
- 브라우저에서 파일 다운로드 동작이 발생하도록 `attachment` 헤더 설정
- 단일 파일과 ZIP 파일 모두 동일한 응답 구조로 처리
