### 4. 장시간 강의 분할 처리

한 강의 시간이 180분을 초과하는 경우 배정 가능한 시간 단위로 분할하여 시간표 생성 로직에 전달

```python
def split_min_per_session(df):
    new_rows = []
    split_id_counter = 1

    for idx, row in df.iterrows():
        min_per_session = row["MinPerSession"]

        if min_per_session > 180:
            split_label = str(split_id_counter)
            split_id_counter += 1
        else:
            split_label = "N"

        first_split = True

        while min_per_session > 180:
            new_row = row.copy()
            new_row["MinPerSession"] = 180
            new_row["Split"] = "Y"
            new_row["Split_ID"] = split_label
            new_rows.append(new_row)

            min_per_session -= 180
            first_split = False

        new_row = row.copy()
        new_row["MinPerSession"] = min_per_session
        new_row["Split"] = "Y" if not first_split else "N"
        new_row["Split_ID"] = split_label
        new_rows.append(new_row)

    return pd.DataFrame(new_rows).reset_index(drop=True)
```

- 긴 강의를 그대로 배정하면 시간 슬롯 충돌 가능성이 커지므로 일정 단위로 분할
- 동일 강의에서 분리된 세션은 `Split_ID`로 묶어 중복 배정 여부 확인 가능
- 시간표 생성 시 교수 중복, 강의 중복, 시간 중복을 더 세밀하게 제어

강의실별 사용 시간을 별도로 관리하여 같은 강의실이 같은 시간에 중복 배정되지 않도록 함

```python
def assign_lecture(lecture, available_rooms):
    non_conflicting_rooms = []

    day = lecture['day']
    start_time = lecture['start_time']
    end_time = lecture['end_time']

    for _, room in available_rooms.iterrows():
        room_name = room['ResourceCode']

        if room_name not in room_schedule:
            room_schedule[room_name] = []

        conflict = any(
            scheduled_day == day and not (
                end_time <= scheduled_start or
                start_time >= scheduled_end
            )
            for scheduled_day, scheduled_start, scheduled_end
            in room_schedule[room_name]
        )

        if not conflict:
            non_conflicting_rooms.append(room)
```

- 중복이 없는 강의실 중 사용 빈도가 낮은 강의실을 선택

```python
if non_conflicting_rooms:
    non_conflicting_rooms = sorted(
        non_conflicting_rooms,
        key=lambda x: room_usage_count[x['ResourceCode']]
    )

    selected_room = non_conflicting_rooms[0]
    room_name = selected_room['ResourceCode']

    room_schedule[room_name].append(
        (day, start_time, end_time)
    )

    room_usage_count[room_name] += 1

    return room_name, selected_room['Capacity']
```

### 8. 제약 조건 검증 및 최적 시간표 선택

생성된 시간표 후보에 대해 강의실 중복, 교수 중복, 수용 인원 초과, 분할 강의 충돌을 검사하고 가장 제약 위반이 적은 시간표를 선택

```python
def check_constraints(final_timetable):
    constraint_violations = []

    room_conflicts = {}

    for idx, row in final_timetable.iterrows():
        room = row['room']
        day = row['day']
        start_time = row['start_time']
        end_time = row['end_time']

        if room:
            if room not in room_conflicts:
                room_conflicts[room] = []

            for scheduled_day, scheduled_start, scheduled_end in room_conflicts[room]:
                if scheduled_day == day and not (
                    end_time <= scheduled_start or
                    start_time >= scheduled_end
                ):
                    constraint_violations.append(
                        f"Room Conflict: {room}"
                    )

            room_conflicts[room].append(
                (day, start_time, end_time)
            )
```

```python
def evaluate_timetable(timetable_result):
    final_timetable, unused_rooms, unassigned_courses = timetable_result
    violations = check_constraints(final_timetable)

    return len(violations) + len(unused_rooms)
```

```python
best_timetable = min(
    results,
    key=evaluate_timetable
)
```

- 단일 시간표를 바로 확정하지 않고 여러 후보를 생성한 뒤 비교
- 제약 위반 수와 미사용 강의실 수를 기준으로 후보 평가
- 최종 결과의 충돌 가능성을 줄이는 선택 구조 적용
